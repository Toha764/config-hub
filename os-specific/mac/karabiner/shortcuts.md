# Karabiner Shortcuts

This configuration sets up a **Hyper key** and some Vim-like movement bindings. 

## Modifiers

| Shortcut | Action |
| :--- | :--- |
| **Caps Lock (Hold)** | Acts as a **Hyper** key (`Shift` + `Ctrl` + `Option` + `Command`) |
| **Caps Lock (Tap)** | Acts as **Escape** |

## Hyper Key Bindings

When holding the **Hyper** key (Caps Lock), the following shortcuts apply:

| Shortcut | Action |
| :--- | :--- |
| `Hyper` + `A` | `Ctrl` + `B` (Tmux Prefix) |
| `Hyper` + `H` | `Left Arrow` |
| `Hyper` + `J` | `Down Arrow` |
| `Hyper` + `K` | `Up Arrow` |
| `Hyper` + `L` | `Right Arrow` |
| `Hyper` + `'` (Quote) | `Delete` / `Backspace` |
